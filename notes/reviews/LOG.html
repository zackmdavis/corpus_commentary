Review log

Which model reviewed what, how the model was verified, and whether the review has been processed. Update this file whenever a review is run or processed.

Model is recorded from the run itself (subagent transcript for Claude subagents; the Codex CLI’s session output for GPT), never from the reviewer’s self-description.

File naming: reviews before 2026-10-18 are notes/reviews/<stem>.md; from 2026-10-18, notes/reviews/<stem>-<reviewer>.md (e.g. 07-whole-dumb-story-gpt.md), so a chapter can have reviews from more than one model. Packets the reviewers read are built by python3 -I tools/make_review_packet.py [stem ...] into notes/review-packets/<stem>.md; rebuild before each run so the packet carries the current draft and summaries.
