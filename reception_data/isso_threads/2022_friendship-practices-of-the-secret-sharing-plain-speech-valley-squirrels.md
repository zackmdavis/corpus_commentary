Thought:

Suppose we have some vector v, representing the e.g. v=x0-x1 the difference between two points x0 and x1.

If x0 and x1 belong to two different groups, we can decompose v = a*vg + vi, where vg is the difference between the group's mean, and vi is some vector orthogonal to vg. If the Mahalanobis D between the groups is large, the a variable will be approximately 1.

So suppose we therefore have v = vg + vi, with vg and vi orthogonal. In that case, the size of v is given by sqrt(||vg||^2 + ||vi||^2). Notably, this function is nonlinear in vg and vi; if ||vg|| >> ||vi||, then ||v|| ≈ ||vg||, while if ||vi|| >> ||vg||, then ||v|| ≈ ||vi||.

So on first impression, it seems like there are multiple conceivable regimes; some where individual differences dominate, some where group differences dominate, and some where both matter.

I'm not sure whether this theory matters for anything. Obviously it's not particularly necessary to use this to compute which regime we are in, as this can also just be found out through people's experience of whether they relate to members of other groups. I guess if one has some theory of what sex differences matter, one can pump those through this model to come up with a prediction for what regime we are in, and see if that prediction matches people's feeling (or lack thereof) of not being understood by members of other groups.
